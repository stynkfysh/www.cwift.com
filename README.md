# www.cwift.com: Cwift, 24-hour desktop appraisals

Static site for **Cwift**, the 24-hour desktop appraisal service of Brian Ward Appraisal
(parent: https://www.brianward.com; sister site: https://date-of-death.com).

- `public/`: deploy root (Cloudflare Pages build output directory). Plain HTML/CSS/JS, no build step.
- `functions/api/`: Pages Functions. `order.js` (order form via Resend), `upload-photos.js` (photos to Google Drive), `form-token.js`.
- Generated by `_tools/generator/` (build.py, lib.py, content_core.py, content_purposes.py, areas_com.py) in the iCloud project folder; not deployed.
- Area pages: `/california/<slug>`, 207 of them (58 counties with San Francisco as one city-and-county page, plus 150 cities and
  neighborhoods). Facts: `_tools/generator/areas/master.json`. Copy: `areas/com_b1.json`..`com_b8.json`. Photo pools: `areas/images_com.json`
  with the photos in `images_src/images/areas/`. The copy pipeline (fact batches, writer briefs, validators, post-edits, image prompts)
  is kept in `_tools/area_pipeline/`.
- Rebuild: `cd _tools/generator && TURNSTILE_SITEKEY=<cwift.com site key> python3 build.py <out_dir>`, then copy `<out_dir>/public`
  over `public/` and add the two credibility PDFs. Run `validate_cwift.py` and `dupcheck.py` before deploying.

Pages settings: framework None, build command empty, output directory `public`.
Env vars: RESEND_API_KEY (secret), RESEND_FROM, RESEND_TO, FORM_SECRET (secret), TURNSTILE_SECRET_KEY (secret),
GOOGLE_SERVICE_ACCOUNT_EMAIL, GOOGLE_PRIVATE_KEY (secret), GOOGLE_DRIVE_PHOTOS_FOLDER_ID.
