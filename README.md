# www.cwift.com: Cwift, 24-hour desktop appraisals

Static site for **Cwift**, the 24-hour desktop appraisal service of Brian Ward Appraisal
(parent: https://www.brianward.com; sister site: https://date-of-death.com).

- `public/`: deploy root (Cloudflare Pages build output directory). Plain HTML/CSS/JS, no build step.
- `functions/api/`: Pages Functions. `order.js` (order form via Resend), `upload-photos.js` (photos to Google Drive), `form-token.js`.
- Generated by `_tools/` (build.py, lib.py, content_core.py, content_purposes.py) in the iCloud project folder; not deployed.

Pages settings: framework None, build command empty, output directory `public`.
Env vars: RESEND_API_KEY (secret), RESEND_FROM, RESEND_TO, FORM_SECRET (secret), TURNSTILE_SECRET_KEY (secret),
GOOGLE_SERVICE_ACCOUNT_EMAIL, GOOGLE_PRIVATE_KEY (secret), GOOGLE_DRIVE_PHOTOS_FOLDER_ID.
